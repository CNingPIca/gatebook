# GateBook 候机书 v1.1

可 3D 打印的旅行箱折叠桌。合起来是一本 A5 精装书（213 × 151 × 40 mm，约 500 g）；在候机口翻下两块侧板，立在行李箱顶上，居中位于两根拉杆之间，用两根系留带绑住拉杆。横把手完全空出，推拉不受影响。

打印机：拓竹 H3C（330 × 320 × 325 mm，多材料）。材料：PETG + TPU 95A。零螺丝。

## 功能

| 功能 | 关键尺寸 |
|---|---|
| 侧板腿（纵向承力，外撇 5° 受压自锁，底边拱起） | 2 × 140 × 92 × 6 mm，桌面高于箱顶约 13 cm |
| 双管系留（TPU 带 + 带扣，或 15 mm 魔术贴） | 适配管距 150–280 mm |
| 旋转桌板（前中心销轴，0° / 180° 定位） | 151 × 213 mm，TPU 防滑面 |
| 伸缩杯架（3 节套环，45° 锥面自定心，TPU 摩擦圈） | Ø86 → Ø61，深约 75 mm |
| 登机牌夹层（桌板内部，TPU 倒刺片） | 88 宽 × 188 深 × 2.2 mm |
| 手机竖立槽（后仰 15°，底部走线孔） | 槽宽 13 mm |
| 收纳格、SIM 卡针孔 | 大格 90 × 90 mm 等 |
| 拉杆挂钩（绑在管上，≤1.5 kg）、小双钩 | — |

## 文件

- `print/`：13 种零件 STL（`_PETG.stl` / `_TPU.stl` 坐标一致，Bambu Studio 中作为一个多零件对象导入后给 TPU 部分指定 TPU 耗材）；3 块打印板 3MF（A 主体 + 桌板，B 侧板与小件，C TPU 带）。
- `step/`：每个零件 STEP + 整机装配 STEP（使用状态）。
- `renders/`：产品渲染图。
- `cad/`：CadQuery 参数化源码。`params.py` 改尺寸/公差 → `python3 export.py` 重新导出；`assembly.py` 做装配干涉检查；`mech.py` 做受力校核。
- `versions/v1.0/`：单管夹版本（力矩校核不通过，已停用），并列保存备查。

## 打印参数（建议）

0.4 mm 喷嘴，0.20 mm 层高；3 墙（桌板、侧板 4 墙）；顶底 5 层；15% 螺旋体填充（侧板 25%）；无需支撑；桌板登机牌夹层有 88 mm 桥接，打开"加厚桥接"。耗材约 PETG 460 g + TPU 40 g。

## 组装

1. 杯架套环 A → B → C 依次从主体顶面放入。
2. 桌板盖上，桌板销轴从上压入，底部"咔"一声卡住。
3. 侧板铰链节放进主体侧边槽，铰链销从后壁沉孔推到底。另一侧同样。
4. 可选：4 颗 Ø6 × 3 mm 磁铁（主体后壁顶面 2、桌板底面 2），按相吸极性压入。

## 使用限制

桌面 ≤ 1 kg 随手物品，不要倚靠或坐压；拉杆挂钩 ≤ 1.5 kg；倾斜拖行前取下杯子；箱顶需大致平整。

## 力学校核摘要（`cad/mech.py`）

| 项目 | v1.0 单管夹 | v1.1 站立式 |
|---|---|---|
| 竖向承载 | 扎带摩擦 SF 2.6–5.1 | 侧板受压 SF 93，屈曲 SF 65 |
| 倾覆（正常负载） | SF 1.0–2.0 ✗ | 前倾 SF 33.5（系带） |
| 压桌 5 kg | SF 0.2–0.4 ✗ | 前倾 SF 1.36，桌板弯曲 SF 5.4，销轴 SF 2.3 |
| 空箱侧翻 | SF 2.45，压桌 0.54 ✗ | SF 19.4 |

假设：PETG 层内 38 MPa / 层间 20 MPa / 剪切 20 MPa / E 1800 MPa；TPU 95A 25 MPa；TPU–铝摩擦系数 0.6。
